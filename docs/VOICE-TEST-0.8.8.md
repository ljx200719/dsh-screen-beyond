## F. 快速自检（不想点界面时）

```powershell
# 插件与运行时版本
Invoke-RestMethod http://127.0.0.1:8900/api/version | Select-Object version
Invoke-RestMethod http://127.0.0.1:8900/api/voice/settings | ConvertTo-Json -Depth 4

# 模型文件在不在、大小对不对
Get-ChildItem "$env:USERPROFILE\.dsh\speech-to-text\sensevoice\models" -Recurse -File |
  Select-Object @{n='MB';e={[math]::Round($_.Length/1MB,2)}}, Name

# 看屏幕语音的状态（为什么没触发）
Invoke-RestMethod http://127.0.0.1:8900/api/watch-screen | ConvertTo-Json -Depth 4
```
