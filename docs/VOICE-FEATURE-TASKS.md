> 当前插件版本：0.8.0  
> 目标：在 DSH 原生面板里实现「她说话 / 你说话 / 语音对话」三条能力，全部按钮控制。

## 0. 一句话

保留现有文字聊天作为主通道，新增：

1. **TTS：她说话**  
   - 用户自己的云 TTS Key / 自建 TTS 服务优先
   - 免费 TTS 至少一个
   - 本地神经 TTS 作为高级选项
2. **ASR：你说话**  
   - 按键录音，不后台常听
   - 本地 ASR 作为离线选项
   - 转文字后由你确认发送
3. **语音对话：双向**  
   - 按钮开始/结束
   - 不做自动播放、自动发送、唤醒词
4. **主动看屏幕语音**
   - 独立子开关，只在打开时生效
   - 低频、可停止、不打断你

## 2. 三个语音能力

### 2.1 TTS：她说话

**目标**

- 她回复后可以生成语音
- 聊天页显示为可播放的语音消息
- 点一下播放，再点停止
- 失败时保留文字，不丢回复

**Provider 优先级**

1. 用户自己配置的云 TTS（付费/免费额度均可）
2. 用户自建 HTTP TTS 服务
3. 免费在线 Edge TTS（至少一个免费选项）
4. 本地神经 TTS（高级选项）
5. Windows SAPI（离线兜底）

**质量目标**

- 中文自然度优先
- 角色音色稳定
- 不承诺“100% 音质”，因为无法验收“完美”
- 付费云 TTS 和本地大模型 TTS 目标为最高档
- Edge TTS 目标为“免费里可用”
- SAPI 目标为“没网也能出声”

**必须**

- 每个角色独立 `voice.json`
- 每个角色独立音色/语速/音调
- 文本清洗：去掉 Markdown/动作旁白，不把括号动作读出来
- 音频缓存：相同文本 + 音色 + 参数不重复合成
- 音频文件存储、清理、大小限制
- 失败回退：TTS 失败只影响语音，不影响文字
- 播放/停止/重播
- 全局静音/停止
- 不自动播放

**不做**

- 不做克隆他人声音
- 不把 API Key 写进聊天、日志、记忆
- 不默认把长文本整段念出来；需要长度上限

### 2.2 ASR：你说话

**目标**

- 插件面板输入框旁有麦克风按钮
- 按住说话或点击开始/结束
- 录音转文字放入输入框
- 你确认后按发送

**必须**

- 不后台常听
- 不自动发送
- 录音状态有明显 UI
- 取消可丢弃
- 无麦克风权限时给中文提示
- 本地 ASR 可离线使用
- ASR 失败保留输入框，不自动发空消息

**Provider 优先级**

1. 本地离线 ASR（SenseVoice / Whisper / faster-whisper 适配）
2. 用户自建 ASR 服务
3. 在线 ASR（可选，用户配置 Key）

**注意**

- DSH 已有的 experimental voice input 是主聊天框的 SenseVoice，插件面板不能直接复用，需先验证服务接口。
- 如果无法复用，就在插件运行时做独立 ASR 适配层。

### 2.3 语音对话：双向

**第一版**

- 明确按钮「开始语音对话 / 结束语音对话」
- 说话用按键半双工
- 她回复后生成语音
- 点击播放，不自动循环
- 不支持打断、唤醒词、后台常听

**后续**

- 流式 TTS
- 语音活动检测
- 回声消除
- 打断/插话
- 低延迟全双工

## 3. 按钮和交互

### 3.1 总按钮：她会不会发语音

位置：聊天页顶部/语音工具栏。

状态：

- **关**：她只发文字；不生成语音消息
- **开**：她的回复带语音消息；聊天里显示播放按钮

规则：

- 总开关关闭时，子按钮不可用
- 总开关打开时，历史语音消息仍可播放
- 不自动播放
- 不自动发送

### 3.2 子按钮：用电脑时主动看屏幕并语音

位置：语音菜单内，独立开关。

规则：

- **默认关**
- 只有打开才允许主动看屏幕
- 必须同时满足总语音开
- 有冷却时间
- 有安静时段
- 你正在说话/录音时不开口
- 不连续截图
- 只描述看到什么，不直接替你回答问题
- 可以随时关闭
- 关闭后立即停止主动语音

建议默认值：

- 检查间隔：低频（例如 15–30 分钟级别，可配置）
- 安静时段：跟随生活模拟/用户设置
- 单次最多一句
- 不打断当前语音播放

### 3.3 麦克风按钮

- 按住说话 / 点一下开始，再点结束
- 录音中显示电平和计时
- 转写后插入输入框
- 你可以编辑
- 你按发送才发

### 3.4 聊天消息播放

- 每条她的语音消息有播放/停止按钮
- 点击播放
- 再点停止
- 支持重播
- 不自动播放
- 不自动下一条
- 不自动朗读整段历史

### 3.5 状态组合

| 总语音 | 子按钮 | 行为 |
|---|---|---|
| 关 | 关 | 纯文字 |
| 开 | 关 | 她发语音消息，可点播放；不主动看屏幕 |
| 关 | 不可用 | 子按钮禁用 |
| 开 | 开 | 允许低频主动看屏幕并语音说一句 |

## 4. 数据与接口

### 4.1 每角色配置 `voice.json`

沿用现有契约，扩展：

```json
{
  "enabled": true,
  "provider": "cloud-http | command | local | edge | sapi",
  "endpoint": "http://127.0.0.1:9880/tts",
  "apiKeyRef": "本地密钥引用，不存明文",
  "model": "用户自己的模型/音色 ID",
  "voice": "音色参数",
  "speed": 1.0,
  "pitch": 0,
  "format": "mp3",
  "maxChars": 300
}
```

要求：

- 密钥只在本机保存
- 不把 Key 放聊天/日志/记忆
- 支持环境变量/本地文件/DPAPI 引用
- 支持每角色独立配置

### 4.2 消息结构

语音消息在现有消息上增加：

```json
{
  "audio": "/voice/audio/<file>.mp3",
  "audioDuration": 3.2,
  "audioProvider": "edge",
  "audioVoice": "xxx"
}
```

要求：

- 文字永远保留
- 音频只是附加物
- 音频生成失败不影响消息

### 4.3 API 草案

```text
GET  /api/voice/settings
POST /api/voice/settings
POST /api/voice/tts
POST /api/voice/asr
GET  /voice/audio/<file>
POST /api/voice/preview
```

原则：

- 业务 API 继续走现有版本
- 音频文件只允许受控目录
- ASR 上传大小限制
- 不允许任意 URL 拉取

## 5. Provider 对比

### TTS

| 方案 | 音质 | 费用 | 离线 | 安装 | 适用 |
|---|---|---|---|---|---|
| 用户云 Key | 高 | 用户自己付 | 否 | 简单 | 主路线 |
| 自建 TTS 服务 | 取决于模型 | 自建 | 可离线 | 中 | 主路线 |
| Edge TTS | 中上 | 免费 | 否 | 简单 | 至少一个免费 |
| 本地神经 TTS | 高 | 硬件成本 | 是 | 复杂 | 高级选项 |
| Windows SAPI | 低 | 免费 | 是 | 系统自带 | 离线兜底 |

### ASR

| 方案 | 识别 | 费用 | 离线 | 安装 | 适用 |
|---|---|---|---|---|---|
| DSH SenseVoice | 中上 | 免费 | 是 | 已有 | 优先验证复用 |
| 插件本地 SenseVoice/Whisper | 中上 | 免费 | 是 | 中 | 本地离线选项 |
| 自建 ASR 服务 | 取决于模型 | 自建 | 可离线 | 中 | 可选 |
| 云 ASR | 高 | 用户付 | 否 | 简单 | 可选 |

## 6. 安全与隐私

- 麦克风必须用户点击后才录音
- 录音时必须明显显示状态
- 不后台常听
- 不上传录音除非使用在线 ASR
- 屏幕主动语音默认关
- 在线 TTS 会把文本发给对应服务；设置里要写清
- 免费 Edge TTS 是第三方接口，可能失效/限流
- API Key 不进日志、不进记忆、不进聊天
- 本地高级方案不把文本/音频发出去
- 子按钮开启时也要能一键停止

## 11. 结论

- 全在线可行，但“不额外花钱”只能靠免费 provider；免费方案质量和稳定性有限
- 高质量 TTS 走用户自己的云 Key / 自建服务
- 本地神经 TTS 是高级选项
- 本地 ASR 是离线选项
- 所有播放、录音、主动语音都由按钮控制
- 不自动播放、不自动发送、不后台常听
- 手机不在本轮，只留 API 契约
