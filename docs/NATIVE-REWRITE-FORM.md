# 屏幕彼端 · 桌面原生化改造需求与决策表单

> 版本：Draft 1（2026-11-14）  
> 用途：把“放弃桌面网页前端、改成 DSH 原生 React 面板”这件事拆成可确认、可验收的工程表单。  
> 填法：在“决策/备注”列填选项字母、✔ 或文字；未填项按“建议默认”执行。  
> 不在本工程范围：手机端 UI、后端引擎重写、新生活玩法、移动端同步实现。

---

## 0. 一句话目标

保留 Node 运行时和全部业务 API，**只把桌面端前端从 iframe 网页改成 DSH 原生 React 面板**；她的屏幕用系统浏览器一键打开；手机端现在不做，但 API/数据契约要留好门。

## 4. 非功能要求

| 编号 | 要求 | 验收 |
|---|---|---|
| N01 | 不使用 iframe 承载聊天/舞台/地图/设置 | 客户端代码检索无相关 iframe |
| N02 | 不写死角色 ID/名字 | 代码无业务级小鲸/小克硬编码 |
| N03 | 后端失败可回退 | 网络断/API 500 有错误态 |
| N04 | 性能 | 聊天滚动流畅；舞台静态 CPU 可接受；无每秒重建 DOM |
| N05 | 数据安全 | 不新增明文密钥；API token 可选；路径校验 |
| N06 | 迁移 | 旧 web 页面删除不破坏 API/数据 |
| N07 | 发布 | 旧版可回滚；备份脚本覆盖新文件 |
| N08 | 兼容 | DSH 当前版本；Node >= 18 |
