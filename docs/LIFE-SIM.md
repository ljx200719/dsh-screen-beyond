# 生活模拟与主动事件设计（2026-11-13 确认版）

## 目标

角色不是只在地图里被动显示，而是有持续运行的生活：

- 后台自己决定做什么
- 会吃饭、看书、写作业、睡觉、闲逛
- 会遇到其他角色、产生互动
- 会记事
- 会在 AI 判断“值得说”时主动到聊天页找用户
- 可以在聊天消息里发照片
- 用户可用设置控制开关、频率和免打扰

## 1. 状态模型

每个角色一份持久化生活状态：

```json
{
  "characterId": "xiaojing",
  "mapId": "map-main",
  "placeId": "home",
  "scene": "home",
  "position": { "x": 0.4, "y": 0.7 },
  "behavior": {
    "type": "eat",
    "label": "吃饭",
    "startedAt": 1760000000000,
    "endsAt": 1760001800000,
    "hotspotId": "餐桌"
  },
  "energy": 62,
  "mood": "平静",
  "lastDecisionAt": 1760000000000,
  "lastEventAt": 1760000000000
}
```

- 每个角色独立
- 位置、行为、持续时间都持久化
- 服务重启不丢
- 聊天/地图/记忆都读这一份状态

## 2. 后台模拟循环

- 服务端常驻循环，不依赖地图页是否打开
- 每秒/每几秒推进计时，但不每秒调用 AI
- 行为按真实时长进行（睡觉 6–9 小时、看书 30–90 分钟等）
- 行为结束、遇到角色、发生值得记录的事时，进入“决策点”
- 决策点才调用 AI；普通 tick 只推进时间和位置

## 3. AI 决定行为

AI 在决策点返回结构化结果：

```json
{
  "behavior": "read",
  "placeId": "library",
  "hotspotId": "书架",
  "durationMinutes": 45,
  "reason": "下午想安静看书"
}
```

- 输入：当前时间、体力、心情、地点、最近行为、最近聊天、记忆摘要
- 输出：下一步行为、地点、时长
- AI 失败/超时：本地规则回退
- 调用频率：每个行为结束一次，不按帧

## 4. 事件判断

行为结束、遇到角色、完成重要事情时，构造候选事件。

AI 一次判断：

```json
{
  "tellUser": true,
  "message": "今天食堂的汤有点咸，但米饭很好吃。",
  "image": {
    "shouldSend": true,
    "prompt": "手机拍的食堂一餐，热汤和米饭，生活感"
  },
  "memory": "今天中午在食堂吃了饭，觉得汤有点咸",
  "importance": 0.4
}
```

- `tellUser` 决定是否发到聊天页
- 不是每个事件都发
- `image.shouldSend` 只在有“刚好拍了/看到”的视觉内容时为 true
- 图片可选，不是每条消息套餐

## 5. 记忆

新增生活事件记忆：

- 今天在哪里做了什么
- 今天遇到谁
- 和谁一起做了什么
- 什么值得以后再提
- 用户最近说过什么

记忆参与：

- 后续行为决策
- 后续主动消息
- 聊天回复
- 多角色互动判断

## 6. 主动消息

- 事件通过判断后写入聊天消息
- 聊天页开着时自动出现
- 聊天页没开时消息保存，下次打开能看到
- 不需要打开地图
- 可附图；附图由事件判断决定

## 7. 多角色、路径碰撞

- 每个角色独立行为状态
- 同场景内计算距离/碰撞
- 相遇、靠近、互动写事件和记忆
- AI 判断“今天遇到谁、要不要告诉用户”
- 路径要尽量绕开障碍；没有可靠障碍数据时至少做角色间避让

## 8. 设置

用户可以控制：

- 主动生活消息：开/关
- 最小间隔
- 每日上限
- 免打扰时间段
- 发图概率
- AI 自由发挥程度
- 是否允许后台继续跑

默认保守：低频、夜间免打扰、图片非必发。

## 9. 图片策略

两类：

1. 聊天页图片
   - 事件触发时 AI 决定是否配图
   - 运行时生成/选取，不预置成套
2. 地图内部图片
   - 不做热点内置图片
   - 等骨骼资源出来后直接控制骨骼动作

## 10. 实施顺序

1. 服务端生活状态 + 持久化 + 后台 tick
2. AI 决策行为 + 本地回退
3. 事件判断 + 记忆
4. 主动消息到聊天页 + 设置开关
5. 多角色互动 + 路径避让
6. 聊天页图片

## 非目标 / 延后

- 骨骼动作和热点内置图：等骨骼资源
- 手机/电脑离线合并同步：已记录，不排期
- 3D 化：当前不做
