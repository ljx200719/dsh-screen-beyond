## E. 主动看屏幕语音（0.8.6）

| # | 步骤 | 预期 | 结果 | 现象 |
|---|---|---|---|---|
| E1 | 设置 → 生活 → 环境权限 → 「她自己看你的屏幕」 | 默认关闭；有「语音说出来」开关，默认「会读出来」 |  |  |

| E7 | 点「关闭」 | 立即不再触发，状态不再更新 |  |  |

## 快速自检（不想点界面时，PowerShell 直接问运行时）

```powershell
# 运行时版本 + 语音配置
Invoke-RestMethod http://127.0.0.1:8900/api/version | Select-Object version
Invoke-RestMethod http://127.0.0.1:8900/api/voice/settings | ConvertTo-Json -Depth 4
Invoke-RestMethod http://127.0.0.1:8900/api/asr/settings  | ConvertTo-Json -Depth 4

# 主动看屏幕：当前为什么没触发 / 是否在录音
Invoke-RestMethod http://127.0.0.1:8900/api/watch-screen | ConvertTo-Json -Depth 4
```

## 已知不做（测的时候不用等）

- 回声消除、流式低延迟、真·全双工（V27 的其余部分）—— 没做
- 唤醒词、后台常听 —— 不做
- 音色训练 / 克隆 / 多音色管理 —— 不做，留 provider 接口
- 手机端语音 —— 不在本轮
