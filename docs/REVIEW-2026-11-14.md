## 2. 本次修正

### 2.1 `requiresLogin` 误判（已修）

**文件**：`runtime/vm-chat.mjs` `analyze()`

原逻辑：

```js
const requiresLogin = !hasConv || /登录|扫码|.../.test(note)
```

问题：只要 AI 没识别出当前会话（冷启动、停在主界面、截图识别漏了），就判定为“登录页”，`sendText` / `sendImageToUser` 会直接拒绝发送，误伤正常主动消息。

修复：

```js
const requiresLogin = /登录|扫码|login|验证码|滑动验证/i.test(note)
```

同时保留 `noConversation` 字段，供后续 UI 提示“没找到会话”，不与登录混为一谈。

### 2.2 `sendImages` 配置未生效（已修）

`GET/POST /api/vm-chat/settings` 支持 `sendImages`，但 `vm-chat.mjs` 里只在注释里提到，实际没有读取。

修复：`sendImageToUser()` 开头检查：

```js
if (cfg().sendImages === false) {
  return { ok: false, error: '虚拟机图片发送已关闭（sendImages=false）' };
}
```

实测：设为 false 后 `/api/vm-chat/send` 带图直接返回该错误；恢复 true 正常。

### 2.3 重复的登录判断（清理）

`sendText()` 和 `sendImageToUser()` 各有一段完全重复的 `if (a.requiresLogin)`，已合并为一段。

### 2.4 Git 遗漏（已补推）
