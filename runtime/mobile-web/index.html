连接这台电脑

在你电脑的面板里打开「设置 → VM → 手机连接」，点生成配对码，把 6 位数字填在这里。

连不上？
  • 手机和电脑要在同一个 Wi-Fi（不是同名不同网）。
  • 浏览器提示证书不安全 → 选「高级 / 继续访问」，这是你电脑自己签的证书，不是外网网站。
  • 证书指纹要和电脑面板上的一致（—）。
  • 配对码 5 分钟内有效、只能用一次；过期就回电脑面板再生成。
  • 连不上还可能是电脑防火墙拦了端口（默认 8920）。
