# 屏幕彼端 · 使用说明

> 📌 看不懂也没关系：装环境那一节可以直接交给 DSH，让它照着帮你装。

## 1. 装环境（可选；想让她能看/操作电脑、屏幕、手机才需要）
纯聊天不用装，打开就能用。想要完整版（她能看屏幕、用电脑、玩自己的手机）才做这一步：

1. 装 **VirtualBox**（官网免费下载，Windows/macOS/Linux 都有）
2. 建一个 Linux 虚拟机（推荐 Debian 桌面版，内存 4~8G、磁盘 40G 就够）
3. 虚拟机里打开 SSH，并把 SSH 端口转发到本机 2222
4. 装好后回到插件，顶部横幅会自动检测成「完整版」
5. 想给她手机：在电脑上装安卓模拟器，建一个 AVD（推荐 **Android 16 / API 36、1080×1920**；目前只验证过 `DSH_Phone` 这个 AVD，真机未适配）。Waydroid 也能用，但截图慢，不推荐


## 2. 打开
- DSH 左侧栏点「屏幕彼端」→ 左边聊天、右边舞台
- 想看她的屏幕：聊天页顶部「屏幕」，或按快捷键 **Alt+S**
- 也可以单独开网页：默认 http://127.0.0.1:8900/
- 页面：聊天 / 地图 / 2D 舞台 / 3D 舞台 / 设置

## 3. 模式与权限
- 纯聊天版：只聊天、记忆、日记
- 完整版：能看/操作电脑、她自己的屏幕、她自己的手机
- 设置 → 环境 里分别开关：关闭 / 仅鼠标键盘 / 代码控制
- 设置 → 环境 →「开始自检」：逐项检查辅助脚本、VirtualBox、虚拟机、模拟器、ADBKeyboard、ffmpeg，缺什么一目了然
- 手机开机后，设置 → 环境 →「安装 ADBKeyboard」可以一键装好中文输入法
- 设置 → 环境 →「⚡ 环境开关」或「看屏幕」页右上角：可以一键关闭 / 启动她的屏幕、手机。屏幕虚拟机约占 **2~6 GB** 内存、手机模拟器约占 **2~4 GB**，不用时关掉省内存
- 「她自己能开机」：不允许（默认）= 屏幕/手机没开时她不会自己启动；允许 = 她想用时可以自己开（会占内存）
- 顶部横幅可自动检测，也可以强制切换

## 4. 角色
- 可切换多个角色，每个角色有独立的人设、记忆、日记、聊天记录
- 可以改名字、称呼你什么、关系、年龄、有没有驾照
- 性格滑块、头像、模型都能改；角色卡可导出/导入

## 5. 聊天
- 文字、图片都能发（📎 发图），她能看懂图片
- 她只会说"有点累 / 快撑不住了"这种，不会报体力数值
- 无括号模式：设置 → 模型 → 聊天风格 → 勾选「无括号模式」，她说话就不会再用括号表示动作/表情（真人不知道自己的血条）
- 她会用工具：记事情、读日记、花钱、看电脑/屏幕/手机
- 回复是边想边打出来的

### 5.5 桌宠

- 设置 → 生活 → 「🐾 桌宠」开启；默认形象是她的头像，也可以「换形象」上传自己的图
- 点 💬 在桌宠上方展开半透明聊天气泡（不是单独窗口），点 👀 让她看看你的屏幕；右键有菜单
- 桌宠下方显示剩余 token / 今日已用；鼠标悬浮可以看完整数字
- 摸头/戳一戳：默认两个区域，会在桌宠气泡里显示她的反应
- 想加自己的互动（搓一搓/喂糖）：编辑数据目录的 `pet.json`，用 `gestures` 的 `hit` 指定图片区域、`prompt` 写她收到的提示；结构见 `runtime/pet/pet.example.json`
- 桌宠状态每 5 秒刷新：在哪里、在干嘛、精力、天气

# 6. 记忆与日记
- 她会自己记住重要的事，也会越久越淡
- 设置 → 记忆 里能看/改/删/置顶，调遗忘快慢
- 每天一篇日记，她可以自己读；你也可以让她念给你听

## 7. 生活
- 作息、活动池、心跳、安静时段都可以自己填
- 打开「智能安排」后，她会按天气/体力/记忆调整作息和活动

## 8. 地图
- 地点可以加、删、拖动，能填描述和她的感受
- 多个地图可以切换；换地图 = 长途旅行
- 可以上传 2D 底图、导入 3D 模型、画自己的道路
- 地点支持导入（JSON / CSV / 每行一个名字）

## 9. 舞台与 3D
- 2D 舞台：地图 + 地点标 + 她的位置
- 3D 舞台：内置 three.js，可拖拽旋转、滚轮缩放
- 她在哪、在走路还是坐车，舞台都会跟着变

## 10. 出行
- 她会按年龄、驾照、体力、天气、钱自己选交通方式
- 未成年人晚上出门要你确认，确认后她会报备
- 跨城市要坐长途（汽车/高铁/飞机），会弹「坐什么中」
- 走累了、下大雨、钱不够，她都会自己换方式或跟你说

## 11. 天气与日夜
- 天气可以手动选，也可以按你电脑定位取真实天气（带温度）
- 雨、雪、风、热、冷在地图和舞台上有不同表现，也能自己上传素材替换
- 日夜自动按时间变（清晨/白天/黄昏/夜晚）

## 12. 经济
设置 → 生活 → 经济 里选货币类型：

- **虚拟货币**：你给她设初始余额、每日零花钱、时薪、吃饭和娱乐开销，交通也按路程扣钱
- **Token 实时代币**：她的钱就是剩下的 token（汇率可设）。聊天花 token 会让她变穷；她为了给你省 token 会舍不得坐车、舍不得花钱（虽然其实省不了多少，但这是设定）

钱不够时她会走路、换便宜方式，或者直接说买不起。余额和剩余 token 在聊天页、地图、舞台、设置里都能看到。

## 13. 设置页
角色 / 生活 / 记忆 / 环境 / 模型 / 数据 / 教程，逐页点就能改。

模型页有「省 token 开关」：按需给工具 / 压缩工具结果 / 批量动作，默认都关，可随时切换。

## 14. 数据与备份
- 所有角色、记忆、日记、地图都在数据目录里（设置 → 数据 能看到地址）
- 整个目录拷走就是备份，换电脑放回去即可
- 导入的模型和图片在 models/ 里

## 15. 常见问题
- 插件里看不到「屏幕彼端」：重启一次 DSH
- 页面打不开：运行时没起来，看设置 → 数据
- 3D 黑屏/卡：显卡或 WebGL 问题，先用 2D 舞台
- 模型不显示：检查路径是否在 models/ 下、文件是否完整
- 地点钉和模型对不上：正常，手动拖钉或用缩放/旋转/偏移对齐
- 真实天气不准：IP 定位有偏差，可切手动
- 她记不住事：检查记忆页是否被清空或归档

## 16. 好看的模型和地图去哪找
内置的 3D 小镇/角色只是占位示例，想要好看的要自己导入：

- 3D 模型：Poly Pizza、Kenney、Quaternius、Sketchfab（挑免费/CC 的），优先 .glb 格式
- 2D 地图：Inkarnate、Azgaar 地图生成器，导出图片上传
- 角色：一张透明 PNG 就能当 2D 小人；3D 角色用 VRM 模型转 .glb
- 不会做也没关系，用内置场景，只改地点名字和描述就能玩
