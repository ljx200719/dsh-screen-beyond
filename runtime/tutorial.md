# 屏幕彼端 · 完整使用说明

> 这一篇覆盖全部功能和主要数值规则。第一次用可以先看「0. 先看这里」，以后再按章节查。

## 0. 先看这里

**先把三种形态分清：**

- **纯聊天版**：不装 DSH、不装虚拟机；Node 18+ + API Key，浏览器直接用。
- **完整版 · DSH 分支**：作为 DSH 插件安装，**不装虚拟机也能用**。聊天、识图、图片回复、记忆、日记、生活、地图/舞台、桌宠、设置/备份都在。
- **完整版 · 虚拟机分支**：在 DSH 分支上再装 VirtualBox 虚拟屏幕 + Android 模拟器；**只新增**她自己的 Linux 屏幕和安卓手机。

**虚拟机和安卓模拟器不是识图、图片回复、聊天、记忆、地图、舞台、桌宠的前置条件。** 只有虚拟屏幕/手机功能需要环境；识图是否可用取决于模型/图片 API。到设置 → 环境页检测时，看到“未检测到虚拟屏幕”不代表只能纯聊天，只代表屏幕/手机工具没开。

- 角色、聊天、桌宠、地图、2D 舞台、设置、备份都可以在本地离线使用；需要模型回复时才调用 API。
- 默认地址：http://127.0.0.1:8900/
- 页面入口：聊天 / 地图 / 2D 舞台 / 3D 舞台 / 设置 / 看屏幕（看屏幕需要环境）。

## 1. 启动与页面

- DSH 左侧栏点「屏幕彼端」进入；也可以直接开网页。
- 聊天页：聊天记录、发图、背景、设置入口。
- 地图页：编辑地点、地图、底图、道路、作息和 3D 配置。
- 2D 舞台：看她当前所在位置、2D 精灵、天气和日夜。
- 3D 舞台：Three.js 场景；只有地图带 3D 资源时才可用。
- 看屏幕：她的 Linux 屏幕、你的 Windows 桌面、她的安卓手机（需要安装/启动环境）。
- 设置：角色 / 生活 / 记忆 / 环境 / 模型 / 数据 / 教程。

快捷键：**Alt+S** 打开看屏幕。

## 2. 角色系统

### 2.1 多角色

- 每个角色有独立的人设、称呼、关系、记忆、日记、聊天记录和钱包。
- 角色之间可以切换；切换后桌宠会自动重启，2D 舞台和聊天会换成新角色。
- 当前已有：小鲸、小克。也可以新建角色、导入/导出角色卡、删除角色。
- 删除角色会连同她的记忆、日记、聊天一起删除，操作前会二次确认。

### 2.2 角色资料

- 名字、怎么称呼你、关系描述、年龄、是否有驾照。
- 性格滑块：话多、主动、撒娇、粘人、吐槽、情绪起伏、嘴硬、好奇心。
- 头像、2D 精灵图、3D 模型地址、模型缩放/旋转/高度偏移。
- 「无括号模式」：开启后她说话不再用括号写动作和表情。

### 2.3 2D 与 3D 资源

- 2D 精灵：透明 PNG，按角色放在宠物资源目录；站姿图会用在 2D 舞台和桌宠。
- 3D 模型：`.glb` / `.gltf`，放在 `models/`，填写 `/models/xxx.glb`。
- 系统会检查资源：
  - 地图有 2D 底图 → 显示 2D 舞台。
  - 地图 `has3d` 为真或填了 3D 模型 → 3D 舞台可用。
  - 只有 2D 的地图打开 3D → 显示「这张地图没有 3D 资源」。
  - 只有 3D 的地图打开 2D 舞台 → 显示「这张地图没有 2D 资源」。
- 2D 舞台永远只走 2D，不会把 3D 硬塞进去。

## 3. 聊天

- 发文字、发图片；她能看懂图片内容。
- 回复是异步生成的，聊天气泡会边想边显示。
- 她能调用工具：记忆、日记、钱包、天气、看屏幕、操作环境等。
- 她不会主动报体力、血条数值，只会说累不累、困不困。
- 省 token 设置：按需给工具、压缩工具结果、批量动作，默认关闭，可随时开。
- 模型默认：deepseek-flash，推理等级 low，温度 0.9，单轮输出上限 900 tokens，工具循环上限 20 步。
- 想换模型/API Key：设置 → 模型。

## 4. 桌宠

### 4.1 开关和形象

- 设置 → 生活 → 桌宠：开启/关闭/重启。
- 默认形象是角色头像；也可以上传自定义图片。
- 换角色后桌宠会自动重启，避免还显示上一个角色。

### 4.2 桌宠界面

- 左侧：悬浮属性四框（名字 / 地点 / 当前活动 / 精力），平时隐藏，鼠标移上去才出现。
- 右侧竖排按钮：聊天、看屏幕、大小。
- 脚下：余额/今日消耗胶囊。
- 桌宠状态每 **5 秒**刷新一次。
- 表情停留：摸头/搓脸/看屏幕均约 **0.6 秒**，随后回到待机。
- 拖动桌宠可移动；拖动阈值 18 像素，轻点不会误触拖动。

### 4.3 互动

- 摸摸头：头部区域，闭眼、脸红。
- 搓一搓：脸颊区域，鼓脸、闭眼。
- 戳一下：身体区域，回到害羞反应。
- 互动时会向服务端发送动作和提示，她会在聊天/状态里回应。
- 桌宠气泡默认只在互动或悬停时出现；完整数字可悬浮查看。
- 大小按钮循环：240 / 300 / 360 像素。

### 4.4 自定义互动

- 配置文件：数据目录 `pet.json`，结构参考 `runtime/pet/pet.example.json`。
- `gestures` 里每个项目包含 `hit`（x/y/w/h 归一化区域）、`prompt`（她收到的动作描述）、`bubble`（短气泡）。
- 修改后重启桌宠生效。

## 5. 地图

### 5.1 地点与底图

- 地点可以添加、删除、拖动；每个点有名字、图标、描述、她在这里的感受。
- 支持导入地点：JSON / CSV / 每行一个名字；也支持导出地点。
- 2D 底图支持上传图片、填写图片地址、清除。
- 地点坐标是 0~1 归一化坐标；拖动后点「保存地图」。
- 地图全宽默认 **2000 米**，比例尺和出行距离都会跟着变。

### 5.2 道路

- 「画道路」进入编辑模式：点地图加点，可撤销、清空、保存。
- 保存后 2D 地图显示绿色虚线路径，3D 舞台会按这些路生成道路。
- 「路径显示」开关可以隐藏/显示 2D 绿色路径。
- 跨河路段会自动补桥。
- 不画路时会走内置道路。

### 5.3 多地图与 2D/3D

- 顶部「+ 新地图」：创建一张只带 2D 底图和地点标的新地图，并自动切过去。
- 「改名」：改当前地图名字。
- 「删地图」：至少保留一张。
- 2D-only 地图的 3D 预览会提示无资源。
- 「应用载具模型」：汽车/自行车 GLB 路径，留空恢复内置形象。
- 「应用地图模型」：带 `has3d` 判定，清空模型会关闭 3D。
- 「用内置 3D 场景」：切到内置示例小镇。
- 「应用地图模型」和「画道路」只影响地图/3D 展示，不会改 2D 地点坐标。

### 5.4 地图点位规则

- 地点位置和地图底图无关，按归一化坐标落点。
- 2D 舞台和 3D 舞台共用同一组地点坐标。
- 2D 底图歪、点位偏，先检查是否上传了正确图片、是否拖过点；点位不会自己移动。

## 6. 舞台

### 6.1 2D 舞台

- 使用官方 2D 底图，叠加地点标和角色 2D 精灵。
- 显示当前位置、天气、日夜、体力文字。
- 2D 舞台不显示 3D 模型，也不提供 3D 入口。
- 角色移动、坐车时，位置会按路线动画走。

### 6.2 3D 舞台

- 只有地图有 3D 资源才工作。
- 拖拽旋转、滚轮缩放。
- 支持导入 `.glb/.gltf` 地图和角色模型。
- 当前内置角色是程序化 chibi；小克为橙发米白裙配色。
- 3D 页面没有资源时会直接显示无资源提示，不渲染空白场景。

## 7. 生活、体力与出行

### 7.1 生活节奏

- 默认心跳：**45 分钟**检查一次。
- 安静时段：默认 **02:00-07:00**；安静时段不主动打扰。
- 主动消息：默认关闭；开启后每 30~90 分钟可能发一次，且最近 20 分钟聊过就不发。
- 日记：默认每天 **22:00** 自动写。
- 作息和活动池都可以改；活动有权重、最短/最长分钟、限定时间段。

### 7.2 体力

- 体力范围 0~100，默认 82，取整。
- 在家休息/睡觉/看视频/玩手机等会恢复：在家约 **2.2/小时**；咖啡店/图书馆/公园/河边约 **0.6/小时**；在其他地点发呆/看视频约 **1.4/小时**。
- 健身/运动约 **-2.6/小时**；上课/学习/工作约 **-1.6/小时**。
- 出行按公里消耗体力：
  - 步行 7/公里、骑车 3.5/公里、公交 1.4/公里、地铁 1.2/公里、自驾 0.6/公里、长途汽车 1.2/公里、高铁 0.8/公里、飞机 2.2/公里。
  - 雨/雪天步行、骑车再乘 **1.15**。
- 体力低于 25 且要走超过 1500 米，她会拒绝走；体力低于 10 更明显。

### 7.3 自动选交通

- 小于 800 米：体力够就走路，体力低于 20 坐公交。
- 800~2500 米：看体力选骑车/公交。
- 2500~6000 米：公交/地铁。
- 大于 6000 米：有驾照可自驾，否则地铁/公交。
- 速度（米/秒）：步行 1.3、骑车 4.2、公交 8.3、自驾 13.9、地铁 16.7、长途汽车 22、高铁 83、飞机 250。
- 夜间 **22:00-06:00**：未成年人去非家地点需要你确认；确认后她会报备。
- 跨地图是长途：距离约 **180~800 公里**，按距离选长途汽车/高铁/飞机；车票会花钱。
- 钱不够时她可能改走路、换便宜交通，或者直接和你说买不起。

### 7.4 交通费用

- 默认基础价：步行/骑车 0，公交 2，地铁 2，自驾 10，长途汽车 15，高铁 30，飞机 80。
- 每公里加价：公交 0.6、地铁 0.6、自驾 1.2、长途汽车 0.8、高铁 0.5、飞机 0.6。

## 8. 经济

- 设置 → 生活 → 经济。
- 虚拟货币：初始 200，每日 20，时薪 15，吃饭 12，娱乐 30；交通按上表扣钱。
- Token 实时代币：余额就是剩余 token；默认预算 2,000,000 token，1000 token 约等于 1 元。
- Token 模式下，聊天花 token 会让她变穷；她可能会为了省 token 舍不得坐车/花钱。
- 钱不够时她会换便宜方式或拒绝。

## 9. 记忆与日记

- 她会自动记住重要的事；记忆会随时间和提及次数变化。
- 默认半衰期 5 天，遗忘阈值 0.12，每轮最多注入 8 条。
- 设置 → 记忆：查看、置顶、删除、恢复归档、导出、导入。
- 日记每天一篇；可以让她自己读，也可以把今天的日记给她看。
- 记忆和日记按角色独立存放。

## 10. 屏幕、手机与环境（可选，仅影响屏幕/手机）

- **环境是可选分支，不是完整版的全部**：DSH 分支不装虚拟机也能聊天、识图、发图、记忆、地图/舞台、桌宠；只有她自己的屏幕/手机需要 VirtualBox 和 Android 模拟器。
- 所有角色共享同一套环境，不做每角色独立虚拟机：一台 Linux 屏幕、一台安卓模拟器、你的 Windows 电脑。
- 权限分：关闭 / 仅鼠标键盘 / 代码控制。
- 屏幕虚拟机约占 **2~6 GB** 内存，手机模拟器约占 **2~4 GB**；不用时建议关掉。
- 「她自己能开机」默认不允许；允许后她需要时会自己启动。
- 设置 → 环境 →「开始自检」检查 VirtualBox、虚拟机、模拟器、ADBKeyboard、FFmpeg。
- 安卓推荐 Android 16 / API 36、1080×1920；目前主要验证 `DSH_Phone` 模拟器。
- 看屏幕快捷键：Alt+S。

## 11. 模型、图片与省 token

- 模型：名称、推理等级（低/中/高/最高）、温度、单轮输出上限、工具循环上限。
- DeepSeek API Key 可单独填写；DSH 环境通常自动读取。
- 图片反馈：可配置 Seedream / OpenAI 兼容服务；关闭后完全不调用生图 API。
- 省 token：
  - 按需给工具：闲聊不携带屏幕/手机/代码工具。
  - 压缩工具结果：截图缩小、长输出截断。
  - 批量动作：连续点击/输入合并提交。
  - 默认都关闭，按需开启。

## 12. 数据、备份与恢复

- 数据目录：设置 → 数据 查看。
- 所有角色、记忆、日记、聊天、地图、钱包都在数据目录里。
- 手动备份：设置 → 数据 →「立即备份」。
- 系统每天凌晨 4 点后自动备份一次；默认保留最近备份。
- 备份产物在数据目录的 `backups/` 下；也可以使用插件自带的 `scripts/backup.ps1`。
- 恢复：使用 `scripts/restore.ps1 -BackupDir <备份目录>`；恢复前建议再备份一次当前数据。
- 不想碰 PowerShell 执行策略：直接双击插件 `scripts/backup.cmd` / `scripts/restore.cmd`，它们已用 `-ExecutionPolicy Bypass` 调用对应脚本。
- 导入的图片和模型在 `models/` 下；换电脑一起带走。

## 13. 常见问题

- 插件里看不到「屏幕彼端」：重启 DSH。
- 页面打不开：检查运行时是否启动、端口 8900 是否被占用。
- 3D 黑屏：先确认地图有 3D 资源；再检查 WebGL/显卡。
- 2D 舞台没角色：检查角色 2D 精灵图和资源路径。
- 点位和底图对不上：检查底图是否换过、地点是否拖动过；坐标不会自动移动。
- 真实天气不准：IP 定位有偏差，可切手动天气。
- 她记不住：看记忆页是否被清空或归档。
- 点按钮没反应：先刷新页面；如果还是不行，查看设置 → 数据/环境自检。

## 14. 资源制作与导入

- 2D 地图：Inkarnate、Azgaar 等工具导出图片，上传到底图。
- 2D 角色：透明 PNG，一张站姿图即可。
- 3D 地图/角色：优先 `.glb`；放在 `models/`，路径填 `/models/xxx.glb`。
- 角色模型比例：先填 1，再按 0.1 步进调到合适；3D 舞台预览可拖拽查看。
- 不会做也没关系：用内置 2D 地图/3D 小镇，只改地点名字、描述和位置就能用。
